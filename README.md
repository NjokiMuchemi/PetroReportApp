# Petro Report App V3.0 - Management Intelligence Suite

Run:

```powershell
pip install -r requirements.txt
python -m streamlit run app.py
```

V3.0 adds:
- Data Validation Center and Report Confidence Score
- Bottom 5 dashboard
- Zone Performance dashboard
- Variance Analysis
- Historical Trend worksheets
- Existing sales, banking, loss, targets, station master, maintenance and history modules retained.
